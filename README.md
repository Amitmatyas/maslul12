ההתראות נשלחות מ-GitHub Actions, בלי שרת נוסף ובלי תשלום.

## הקמה, פעם אחת (בערך 10 דקות)

### 1. להעלות ל-GitHub
1. ב-github.com: **New repository**. השם לבחירתך, למשל `maslul12`, והמאגר צריך להיות **Public** (GitHub Pages בחינם עובד רק על מאגר ציבורי. אין בקוד שום מידע אישי, והיומן נשמר רק בטלפון).
2. מעלים את **כל** הקבצים מהתיקייה `maslul12-app`.
   - ⚠️ התיקייה `.github` מוסתרת ב-Mac. ב-Finder לוחצים `Cmd + Shift + .` כדי לראות אותה, וגוררים גם אותה. בלעדיה לא יישלחו התראות.

### 2. להפעיל את האתר (GitHub Pages)
המאגר → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**.
אחרי דקה-שתיים האתר עולה בכתובת `https://<שם-המשתמש>.github.io/maslul12/`.

### 3. להוסיף את המפתח הסודי
המאגר → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:
- Name: `VAPID_PRIVATE`
- Secret: המפתח מהקובץ `maslul12-secrets-DONT-UPLOAD.txt` (נמצא בתיקיית Training, **מחוץ** לתיקייה הזו. לא מעלים אותו!).

### 4. להתקין על האייפון ולהפעיל התראות
1. פותחים את כתובת האתר ב-**Safari**.
2. כפתור השיתוף → **הוסף למסך הבית**.
3. פותחים את **נמרץ** מהמסך הבית (לא מ-Safari).
4. גלגל השיניים → **הפעל התראות** → **אישור**.
5. **העתק קוד מכשיר**.
6. ב-GitHub (אפשר מהטלפון): Settings → Secrets and variables → Actions → New repository secret:
   - Name: `PUSH_SUBSCRIPTIONS`
   - Secret: מדביקים את מה שהעתקת.

### 5. בדיקה
המאגר → **Actions** → **Nimratz push** → **Run workflow** → `test` → **Run**.
תוך דקה אמורה להגיע לאייפון התראה. אם הריצה אדומה, לוחצים עליה ורואים מה חסר.
